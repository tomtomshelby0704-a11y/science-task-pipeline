# claims/：占用文件

多个对话同时跑同一条口令时，用这里的文件占住“一件事”，避免重复做。一件事一个文件，push 成功才算占到，做完删掉。带租期，占用的会话死了，别人过期后可以接手，不会永久锁死。

目前使用方：[tb-harden](../../../skills/tb-harden/SKILL.md)（`复审改难`）、[tb-research](../../../skills/tb-research/SKILL.md)（`研究出题`）、[tb-quick](../../../skills/tb-quick/SKILL.md)（`快速出题`）。别的 Skill 要用，起新的类型名即可，规则不变。

## 文件名

`<类型>-<对象>.md`，类型与对象都用英文小写、连字符。

| 文件 | 占住什么 | 使用方 |
| --- | --- | --- |
| `harden-score.md` | 给 `runs/scores.md` 补打分（全局一把） | tb-harden 第 2 步 |
| `harden-<原题号>.md` | 把这道原题改难成新题 | tb-harden 第 3–5 步 |
| `research-<素材号>.md` | 加工这份素材的全部候选 | tb-research 第 2 步、tb-quick 第 2 步（两条出题链路共用这把锁，自动互斥） |

## 文件内容

```
# <类型>-<对象>

- **类型**：harden
- **对象**：tbs-018
- **占用者**：<Agent 名称 / 会话标识>
- **开始**：<ISO 时间，带时区>
- **心跳**：<ISO 时间，带时区>
- **租期**：2 小时

## 接手记录（只追加）
```

## 规则

1. **占用**：工作区干净（没有未提交改动、没有未推送提交）时 `git pull --rebase origin main`；目标文件已存在且心跳未过期 → 这件事有人在做，换下一件，不回报。不存在 → 新建文件，**单独一个 commit**，push。push 成功才算占到，占到之前不开始做。
2. **撞上**：push 被拒 → `git rebase --abort`（如在 rebase 中），`git fetch origin`，`git reset --hard origin/main`（本地只有这一个占用提交，按第 1 条的前提这样做是安全的），再看目标文件：已被别人建了 → 换下一件；没有 → 回第 1 条重试。
3. **心跳**：占用者每次推本件事的产物时，同一 commit 里把自己占用文件的“心跳”改成当前时间。长时间计算中途不 push 的，至少每小时推一次只改心跳的 commit。
4. **过期接手**：心跳早于当前时间 2 小时以上，即视为过期，任何 Agent 都可以接手：改“占用者”和“心跳”，在“接手记录”追加一行 `- <时间>：<接手者> 接手，原占用者 <x> 心跳 <时间> 已过期`，commit，push；push 成功才算接到。接手者沿用仓库里已推的产物，接着做。这是 AGENTS.md 并发规则 3“只动自己占到的文件”的唯一例外。
5. **释放**：做完时，在最后一个产物 commit 里 `git rm` 自己的占用文件。放弃不做也要删掉它（单独 commit 也行），不留死锁。
6. 只读不做事的会话（看板、审阅）不需要占用。看板“进行中的占用”表列出全部占用文件，并标出已过期的。
