# 素材

GPT Pro 链路的产出和人类提供的外部题目放这里，**是素材不是题目**。成不成题由 [tb-research](../../../skills/tb-research/SKILL.md)（口令 `研究出题`）判断：能成题的改写进 `topics/<题号>.md` 并入队列，不能成题的否决。不是每份素材都必须成题。

| 文件 | 内容 |
| --- | --- |
| `mat-NNN-prompt.md` | [tb-topic](../../../skills/tb-topic/SKILL.md) 生成的提示词，人类整份复制给 GPT Pro |
| `mat-NNN.md` | 人类把 GPT Pro 回复原样贴回来；格式瑕疵不要紧，加工时会修。也可以是从外部素材整理出的候选（来源对话写明出处） |
| `src-NNN.md` | 人类提供的外部素材原文与原始元数据，附逐条入库表；入库条目拆进对应的 `mat-NNN.md`。入库门槛只挡占位、空条目和重复，见 [tb-topic“外部素材入库”](../../../skills/tb-topic/SKILL.md#外部素材入库) |
| `src-NNN-files/` | 外部素材的小附件（如渲染图），按原编号命名 |

头部状态：`待登记`（刚贴回）→ `待加工`（人类说了 `登记素材`）→ `已加工（→ tbs-XXX）` 或 `已否决（原因一句）`。编号 `mat-NNN` 从 `mat-001` 起顺延。

mat-001 / 002 / 003 原本直接登记为题目 tbs-001 / 002 / 003，2026-10-28 降级为素材重新加工；题号 tbs-001 起重新分配。
