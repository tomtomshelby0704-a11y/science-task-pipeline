# 运行摘要

每道题一个目录 `<题号>/`，由 [tb-run](../../../skills/tb-run/SKILL.md) 在登记台账 1 的同一次提交里推上来，只追加不改旧文件。原始轨迹、题包留在执行机本地，这里只放摘要：

| 文件 | 内容 |
| --- | --- |
| `<题号>/calibration.md` | 执行机 `evidence/calibration.md` 的原样副本：模型名单、全部运行表、弱模型先跑结论、三条件判定、各候选结论 |
| `<题号>/<候选号>-<模型>-<序号>.md` | 每次 `harbor run` 一份摘要，格式见 [模板](../../../skills/tb-run/templates/trajectory.md)；文件名与本机 `runs/<候选号>-<模型>-<序号>/` 目录名一致，如 `1-weak-1.md`、`2-gpt56-3.md` |
| `<题号>/delivery-README.md` | 仅达标题：执行机交付压缩包（[规范](../../../skills/tb-run/delivery.md)）里 `README.md` 的副本，含入包运行表与三条件判定；压缩包本身留在执行机 |

达标与不达标的题都要有；换掉的候选和无效运行也要有。字段来自要求书 [轨迹与运行记录](../../../specs/tb-science-requirements.md#轨迹与运行记录验收标准-12)，脱敏规则写在每份摘要头部。

用途：审查时核对校准记录；以后供复审失败轨迹、挑选可改难的题目的流程读取（尚未建立）。
